# Feature Roadmap

## Overview

This roadmap defines the planned features of the Real-Time Communication Platform.

The roadmap is divided into multiple releases to ensure steady development, maintainable code, and continuous testing. Each version delivers a usable product while laying the foundation for future enhancements.

---

# Version 1.0 - Minimum Viable Product (MVP)

## Objective

### Authentication

- User Registration
- User Login
- Secure Password Hashing
- JWT Authentication
- Protected Routes
- Logout

### User Management

- User Profile
- Profile Picture
- User Search
- User Status (Online/Offline)

### Conversations

- Last Message Timestamp

- Light Theme

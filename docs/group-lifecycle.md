# Group Management (Version 1)

## Purpose

Provide users with a simple and secure way to create, join, and manage group conversations.

---

# Group Creation

Users can create a new group from the **Conversations** page.

## Create Group Form

The following information is required while creating a group:

* Group Name
* Group Profile Picture
* Group Visibility
  * Public
  * Private
* Group Bio *(Optional)*

After clicking **Create Group**, the group is immediately created and the creator becomes the **Group Admin**.

---

# Group Visibility

## Public Group

* Visible in the **Discover** page.
* Any user can search and join the group by clicking the join button.
* No invitation is required.

---

## Private Group

* Hidden from the Discover page.
* Can only be joined using a unique invitation link generated by the Group Admin.
* Users joining through the invitation link become group members automatically.

---

# Group Card

Once a group is created, it appears in the **Friends & Groups** page.

The group card is little different from the private chat card.

## Card Information

* Group Profile Picture
* Group Name
* Last Message
<!-- * Unread Message Indicator -->
* Last Message Timestamp

## Card Interactions

### Profile Picture
* Opens the group profile picture.

### Remaining Card Area
* Opens the group conversation without reloading the page.

---

# Group Conversation

The group conversation is displayed inside the chat component.

## Header

Displays:
* Group Profile Picture
* Group Name

### Header Interactions
* Clicking the profile picture opens the group image.
* Clicking the remaining header opens the **Group Details** panel.

---

# Group Details panel

Displays:
* Group Profile Picture
* Group Name
* Group Bio
* List of Joined Members

The members list is read-only in Version 1 and does not provide additional interactions.

---

# Group Roles

Every group has two user roles.

## Group Admin

The group creator is the only administrator in Version 1.

### Permissions
* In `Group Details panel` of admin, he can see some options like : 
    * Generate Invitation Link
    * Remove Members
    * Change Group Profile Picture
    * Edit Group Bio
    * Delete Group

### Restrictions

* The admin cannot leave the group directly.
* To exit the group, the admin must first delete the group.
* Admin transfer is planned as a future enhancement.
* If he click the delete button directly then all the members will be removed directly and group card and conversations will be deleted.  

---

## Group Member

Users become members by:

* Joining a public group from the Discover page.
* Joining a private group using an invitation link.

### Permissions

* View Group Details
* Send Messages
* Leave Group

Members cannot modify any group settings.

---

# Group Deletion

* Only the Group Admin can delete a group.
* Deleting a group permanently removes the group and its associated conversation history.

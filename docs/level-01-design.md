# Level-1 Navigation Plan

The application follows a simple and communication-focused navigation structure. Each page has a single responsibility, allowing users to quickly perform common communication tasks without unnecessary complexity.

## 1. Home  (Main screen: 1)

The Home page serves as the primary landing page after a user logs in. It acts as the communication dashboard by providing quick access to the most frequently used features.

### Components

<!-- * Recent Chats -->
* Active Friends
* Incoming Friend Requests
* Profile Icon
<!-- * Suggested Friends *(Future Enhancement)* -->

---

## 2. Conversations (page-2.png) (old name was `Friends & Groups`)  (Main screen: 2)

This page allows users to manage their personal network and group memberships. It displays all friends and groups along with their current online or offline status, enabling users to quickly start private or group conversations.

### Components

* Friends List (single user friend)
* Groups List
* Non-Friends Chat List

---

## 3. Discover  (Main screen: 3)

The Discover page is designed to help users find and connect with people across the platform. In Version 1, it will display the list of currently active users (or may be include offline users also - not decided yet). In future versions, this page can be expanded to include user recommendations, suggested groups, and other discovery features.

* All the active users list (or may be include offline users also - not decided yet)
* User Search Bar

### Components

* Currently Active Users 
* Search Results 
* Suggested Users *(Future Enhancement)*
* Suggested Groups *(Future Enhancement)*
